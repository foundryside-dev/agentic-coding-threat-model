# ACF Practitioner Reference

A structured reference for practitioners working with the Agentic Code Failure (ACF) taxonomy, drawn from the discussion paper on AI-assisted software development risk in high-stakes systems.

## Quick Start

| Section | What you'll find |
|---------|-----------------|
| [**ACF Taxonomy**](acf/) | 20 catalogued failure modes (15 core, 5 provisional) organised by STRIDE category — each with generative mechanism, examples, detection approaches, and cross-references |
| [**Threat Model**](threat-model/) | The threat landscape, trust boundaries, guidance gap analysis, and STRIDE category landing pages |
| [**Introduction**]({{< relref "threat-model/introduction" >}}) | Start here for context — the case for a dedicated threat model for agentic code |
| [**Appendices**](appendices/) | Autonomy self-assessment, SQL extension, annotated agent transcript, cross-model defect chaining, systems thinking primer, and glossary |

## At a Glance

- **20 failure modes** catalogued across 6 STRIDE categories (15 core, 5 provisional)
- **2 critical-risk entries** (ACF-T1: Authority Tier Conflation, ACF-E1: Implicit Privilege Grant) with no current automated detection
